# HR Analytics Dashboard

## Project Overview
An interactive HR Analytics Dashboard developed using Microsoft Excel to analyze employee attrition and workforce trends.

## Project Objectives
- Analyze employee attrition and retention.
- Understand workforce demographics.
- Explore job satisfaction and salary trends.
- Identify factors associated with employee attrition.

## Tools & Technologies
- Microsoft Excel
- PivotTables
- PivotCharts
- Excel Slicers
- Excel Formulas and Functions
- Data Cleaning

## Dashboard Features
- Total Employees
- Attrition Count
- Attrition Rate
- Active Employees
- Department-wise Attrition
- Gender-wise Attrition
- Job Role-wise Attrition
- Age-wise Analysis
- Education Field Analysis
- Overtime and Job Satisfaction Analysis
- Interactive Slicers

## Dataset
IBM HR Analytics Employee Attrition Dataset.

## Key Project Details
- Total Employees: 1,470
- Attrition Count: 237
- Active Employees: 1,233
- Attrition Rate: 16.12%

## Project Files
The Excel workbook includes raw data, cleaned data, analysis, PivotTables, and the interactive dashboard.

## Learning Outcomes
Practised data cleaning, data analysis, PivotTables, PivotCharts, and dashboard creation using Microsoft Excel.
